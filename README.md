# 📋 Task Management API & Dashboard (تسک‌من)

یک سیستم مدیریت وظایف (Task Management) کامل و مدرن، شامل یک **API قدرتمند** در بک‌اند و یک **داشبورد زیبا و تعاملی** در فرانت‌اند.

این پروژه با هدف یادگیری عمیق **ASP.NET Core** و ساخت یک نمونه‌کار (Portfolio) واقعی برای ورود به بازار کار طراحی و پیاده‌سازی شده است.

---

## ✨ امکانات و ویژگی‌ها

### 🎯 بک‌اند (Backend)
- ساختار استاندارد با **ASP.NET Core Web API**.
- استفاده از **Entity Framework Core** برای ارتباط با دیتابیس.
- دیتابیس **SQL Server (LocalDB)**.
- پیاده‌سازی کامل عملیات **CRUD** (ایجاد، خواندن، ویرایش، حذف).
- پیاده‌سازی **DTOs** (Data Transfer Objects) برای انتقال امن داده‌ها.
- محاسبه **استریک (Streak)** یا روزهای پیوسته کاری در بک‌اند.
- معماری تمیز و جدا شده (Controllers, Models, Data, DTOs).

### 🎨 فرانت‌اند (Frontend)
- طراحی **مینیمال و مدرن** با استفاده از HTML خالص، CSS و JavaScript (بدون فریم‌ورک سنگین).
- داشبورد کاملاً واکنش‌گرا (Responsive).
- **تم تاریک و روشن** (Dark/Light Mode) با قابلیت تغییر رنگ اصلی برنامه.
- **تقویم شمسی** تعاملی (با استفاده از کتابخانه `jalaali-js`).
- **نقشه حرارتی (Heatmap)** برای نمایش میزان فعالیت روزانه.
- **تایمر پومودورو** برای افزایش تمرکز.
- **ثبت خواب** (طراحی مدال اختصاصی).
- بخش **«دنیای من»** برای دسته‌بندی موضوعات (دانشجویان، ورزش، روتین بندگی و...).
- **نمودار دایره‌ای (Doughnut)** برای نمایش آمار تسک‌های انجام شده.

---

## 🛠 تکنولوژی‌های استفاده شده

- **Backend:** C#, ASP.NET Core 8 (Web API), Entity Framework Core
- **Database:** SQL Server (LocalDB)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6)
- **Libraries:** Chart.js (برای نمودار), jalaali-js (برای تقویم شمسی)
- **Tools:** Visual Studio 2026, Git, Swagger
